## Що реалізовано

| Функція | Реалізація |
| --- | --- |
| **Реєстрація та вхід** | Пароль має містити щонайменше **8 символів**, великі й малі літери, цифру та спецсимвол. Паролі хешуються за допомогою **Argon2id**. |
| **CAPTCHA** | Під час реєстрації відображається зображення з випадковим кодом. Сервер перевіряє відповідь, яку можна використати лише один раз. |
| **Активація акаунта** | Одноразовий токен дійсний **24 години**. У базі даних зберігається його **SHA-256-хеш**. |
| **Захист від підбору пароля та кодів 2FA** | Після **5 невдалих спроб** введення пароля або коду 2FA акаунт блокується на **5 хвилин**. |
| **Ролі та журнал входів** | Користувач має доступ до свого профілю. Адміністратор бачить список акаунтів і журнал із часом, IP-адресою та результатом кожної спроби входу. Він також може блокувати й розблоковувати акаунти. |
| **Двофакторна автентифікація** | У профілі можна ввімкнути або вимкнути **TOTP** із підтвердженням шестизначним кодом. Секрет TOTP зберігається в зашифрованому вигляді. |
| **Вхід через Google** | Використовується **OpenID Connect** із перевіркою `ID token`, `state` і `nonce` та застосуванням **PKCE**. Для налаштування потрібен власний OAuth-клієнт. |
| **Відновлення пароля** | Одноразовий токен дійсний **30 хвилин**. Новий пароль має відповідати тим самим вимогам, що й під час реєстрації. |
